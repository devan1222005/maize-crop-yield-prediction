# 🌽 Maize Crop Yield Prediction

Machine learning-based maize crop yield prediction system developed using Random Forest, Flask, React, and data analysis techniques to estimate crop yield based on environmental and agricultural parameters.

---

## 🚀 Features

- Predicts maize crop yield in tons/hectare
- Machine learning model using Random Forest
- React-based frontend interface
- Flask backend integration
- Environmental and soil parameter analysis
- Interactive user input and prediction system

---

## 🛠 Technologies Used

- Python
- Flask
- React
- Random Forest
- Scikit-learn
- Pandas
- NumPy
- Machine Learning
- Data Analysis

## 📊 Input Parameters

The model predicts crop yield using:

- Sowing Date
- Nitrogen Applied
- Phosphorus Applied
- Soil pH
- Average Temperature
- Average Rainfall
- Average Humidity
- Plant Density
- Seed Type
